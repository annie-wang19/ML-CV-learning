# ML-CV-learning

[English](README.md) | [简体中文](README.zh-CN.md)

记录数学、Python、机器学习、计算机视觉和英语的学习过程。

我目前是一名大三学生，正在为未来的硕士阶段学习做准备。这个仓库用于记录我在机器学习（Machine Learning，ML）、深度学习（Deep Learning，DL）和计算机视觉（Computer Vision，CV）方面的学习，也记录学术英语和雅思备考的进展。我的雅思目标是总分 **7.5**，暂计划在 **2027 年 2 月左右的寒假**参加考试。

我主要利用周末进行系统学习，并借助 ChatGPT 制订学习任务、理解困难概念、检查代码和改进英语表达。我的目标是在保证大学课程学习质量的前提下，逐步做到理解所学内容、写出代码、验证结果，并用自己的话解释清楚。

## 学习目标

- 补好 ML 和 CV 所需的数学基础，同时提升 Python 编程能力。上过相关数学课程，并不代表已经牢固掌握这些知识。
- 学习李宏毅机器学习课程中适合入门的部分。
- 通过 Daniel Cremers 的《Multiple View Geometry》课程学习几何计算机视觉。
- 培养系统使用 AI 辅助编程的习惯，并独立检查和验证结果。
- 通过每日短练习、精选 LeetCode 题目和数学编程任务提升 Python 能力，配合中午提醒和定期复习。
- 持续练习英语听、说、读、写，并开展雅思专项训练。

## 阶段安排

下表中的“学习周”主要以一个周末的系统学习为单位，可以根据理解程度重复，也可以在学校考试期间暂停。

| 学习周 | 主要内容 |
|---|---|
| 第 1–8 周 | 数学基础、Python、NumPy，以及 ML/CV 入门认识 |
| 第 9–12 周 | 回归、分类和模型评估 |
| 第 13–18 周 | PyTorch、神经网络，以及一个小型图像分类项目 |
| 第 19–26 周 | 相机几何、图像匹配，以及一个双视图几何演示 |
| 第 27–28 周 | 整理可复现的成果、复习，以及英文展示 |

数学和英语练习贯穿整个过程。周末暂按 **8 小时**安排，其中保留 **2 小时专门学习数学**。工作日暂安排每天约 **20 分钟 Python 练习和 20 分钟英语练习**；周末的 Python 练习计入已有的编程时间，不重复增加任务。

技术学习计划会延续到雅思考试之后。雅思考前的 **4–6 周**，我会将更多周末时间分配给英语，并相应顺延技术学习进度。实际时间安排将根据学校课程、可用时间和当前英语水平调整。

## 如何记录进步

每个学习周记录一个小型实现或实验、一份简短学习日志、一个尚未解决的问题，以及一段英文总结。同时记录 AI 提供了什么帮助，以及我如何验证它给出的结果。

计划完成的两个成果是：**一个图像分类实验**和**一个双视图几何演示**。它们目前是学习目标，尚未完成。
